# Implement Client Script & UI Policy (Incident)

## Project Title
Implement Client Script & UI Policy (Incident)

## Platform
ServiceNow

## Module
Incident Management

## Objective
To enforce data integrity on Incident records using UI Policies and Client Scripts.

## Features
- High Impact UI Policy
- Urgency field control
- Auto-set Urgency using onChange Client Script
- Save validation using onSubmit Client Script
- Prevent State changes through list editing
- Incident form testing and validation

## Technologies
- ServiceNow
- UI Policies
- UI Policy Actions
- Client Scripts
- Incident Management

## Project Outcome
This project demonstrates how UI Policies and Client Scripts can be used together to control Incident form behavior, automate field updates, and prevent invalid data submission.
