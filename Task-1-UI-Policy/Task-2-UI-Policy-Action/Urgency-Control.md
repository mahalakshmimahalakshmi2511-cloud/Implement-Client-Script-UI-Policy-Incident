# Task 2 – UI Policy Action

## UI Policy
High Impact Control

## Field
Urgency

## Configuration
- Field Name: Urgency
- Read-only: True
- Visible: Unchanged

## Purpose
When the Incident Impact is set to High, the Urgency field becomes read-only.

## Expected Result
- Impact = High → Urgency becomes read-only
- Impact changed from High → UI Policy is reversed
- Urgency becomes editable again
